# Akaunting Deployment on AWS

## Architecture
EC2 → Nginx + PHP → RDS MySQL

## Steps
1. EC2 setup
2. Nginx + PHP install
3. Akaunting deployment
4. RDS setup
5. Connection via .env

## Database Config
DB_HOST=...
DB_DATABASE=akaunting
DB_USERNAME=admin
DB_PASSWORD=...

## CRUD
- Create: Add expense
- Read: View expense
- Update: Edit expense
- Delete: Remove expense
